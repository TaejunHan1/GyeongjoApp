## 수정 내용

### 1. 헤더 레이아웃

**이전 (틀린 방식):** 취소/이전 버튼이 콘텐츠 하단에 배치

**수정 후 (올바른 방식):**
```
handle bar
[← 이전]   제목   [✕ 취소]
```
- Step 1: 좌측 빈 공간(32px) + 제목 + 우상단 [✕]
- Step 2, 3: 좌상단 [← chevron-back] + 제목 + 우상단 [✕]
- handlePumasiBack 함수로 단계별 뒤로가기 처리

### 2. 관계 로딩
- ContributionScreen.js 확인 결과 전체 주석 처리 상태
- guest_book relation_category 값이 "신랑 친구", "신부 가족" 형태
- includes('신랑') / includes('신부') 방식으로 필터링 유지

### 3. 다음/확인 버튼 통합
- Step 1, 2: 비활성(선택 전 회색) / 활성(선택 후 파란색) [다음] 버튼
- Step 3: [확인] 버튼 → 시트 닫기
- 모달 내 단일 버튼으로 통합
