## 사용자 피드백

> "무슨 결혼식인지 안나오잖아"
> "누가 토스가 이런식으로 하냐 다음 버튼을 만들어서 진행하지 않아?"

---

## 수정 내용

### 1. 이벤트명 표시 수정
- event_name → 메인 텍스트 (크게)
- event_type → 서브텍스트 (결혼식 / 장례식)
- 선택 상태가 즉시 다음 단계로 넘어가면서 반영 안 되던 문제 함께 해결

### 2. 토스 진행 방식 수정

**이전 (틀린 방식):**
- 항목 탭 → 즉시 다음 단계로 이동

**수정 후 (올바른 토스 방식):**
- 항목 탭 → 라디오 버튼만 활성화 (화면 전환 없음)
- [다음] 버튼 탭 → 다음 단계 이동

**[다음] 버튼 스펙:**
| 상태 | 배경색 | 텍스트 색 |
|------|--------|----------|
| 선택 전 (비활성) | #F2F4F6 | #8B95A1 |
| 선택 후 (활성) | #3182F6 | #FFFFFF |
| borderRadius: 14, paddingVertical: 16, fontSize: 17, fontWeight: '700' |

**단계별 버튼:**
- Step 1, 2: [다음] 버튼
- Step 3: [확인] 버튼 → 시트 닫기
- 각 Step에 [이전] 버튼 (Step 1 제외)
