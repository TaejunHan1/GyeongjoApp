## 의사결정 흐름

1. researcher가 앱 기반 후보 5가지 제안 → 사용자 "다 별로야, 앱에 없는 기능도 괜찮아"
2. team-lead가 한국 경조사 문화 특화 아이디어 5가지 재제안 (A~E)
3. 사용자 "A(품앗이 장부)랑 B(감사 메시지) 둘 다 괜찮아" → 두 위젯 동시 구현
4. frontend가 캘린더 섹션 제거 + 두 위젯 구현 + 빌드 검증 완료

## 회고: 이번 세션 개선 필요사항

1. **회의록 누락**: 팀 운영 중 회의록을 즉시 기록하지 않음 → 종료 후 소급 작성
   - 개선: 앞으로는 각 단계 완료 직후 즉시 회의록 파일 생성
2. **researcher가 파일 저장 불가**: Explore 에이전트는 Write 도구 없음 → team-lead가 내용 수령 후 저장
3. **1차 후보 기각**: 앱 내 기존 데이터 기반 후보만 제안했다가 기각 → 처음부터 넓은 범위로 제안했어야 함
