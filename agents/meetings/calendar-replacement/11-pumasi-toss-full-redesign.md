## 적용된 토스 디자인 원칙

| 요소 | 이전 | 이후 |
|------|------|------|
| 금액 표시 | 일반 텍스트 | fontSize 20, fontWeight 800, letterSpacing -0.5 |
| 요약 | 없음 | 받은 금액(파란) / 낸 금액(빨간) 나란히 요약 카드 |
| 탭 | 기존 | pill 배경 #F2F4F6, 활성 흰색+shadow |
| 리스트 항목 | 텍스트만 | 이니셜 아바타 원 + 이름 + 관계 + 금액 |
| 필터 | 버튼 스타일 | 인라인 칩, 카드 상단에 위치 |
| 줬음 상태 | 색상만 | 왼쪽 상태 바 + 정산완료 체크마크 배지 |
| 빈 상태 | 텍스트만 | 아이콘 + 메인텍스트 + 서브텍스트 |
| 전체 보기 | onPress 없음 | borderTop 구분선 + chevron 아이콘 + 동작 연결 |

## 주요 변경

- 기존 스타일 15개 제거 → pm prefix 스타일 22개로 교체
- widgetSection, widgetCard는 감사 메시지 위젯에서 사용 중이라 유지
