1. **이전 실패 경험**: 직전 세션에서 PM(나)이 혼자 HomeScreen을 토스 스타일로 재설계 시도했다가 사용자로부터 "토스답지 않다, 최악이다"라는 피드백을 받음.
   - 실패 원인: 너무 플랫하게 만들고, 이모지로 아이콘 대체, 섹션을 제거해 공허해짐

3. **agent teams 환경 세팅**: `CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1` 활성화됨 (`~/.zshrc` + `~/.claude/settings.json`).
