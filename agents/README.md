# Agent Teams 프롬프트 템플릿

## 빠른 시작

1. **터미널 열기**
2. **Claude 실행**: `claude --model opus`
3. **프롬프트 선택** → 해당 `.md` 파일 열기
4. **`[기능 설명]` 부분만 바꿔서** 프롬프트 전체를 Claude에 붙여넣기

---

## 파일 설명

| 파일 | 팀 규모 | 사용 시점 |
|------|---------|-----------|
| `simple-team.md` | 5인 | 버튼 추가, UI 수정, 작은 기능 |
| `basic-team.md` | 10인 | 새 화면, API 연동, 일반 기능 |
| `large-team.md` | 12인 | 새 앱 개발, 대규모 리팩토링 |

---

## 정담 앱 예시 프롬프트

### 축의금 통계 대시보드
```
[기능 설명]: 정담 앱의 이벤트 상세 화면에 축의금 통계 대시보드 추가.
하객별 금액 목록, 평균/최대/최소 금액, 시간대별 분포 차트,
카카오톡 감사 메시지 일괄 발송 기능.
```

### 알림톡 연동
```
[기능 설명]: 솔라피 카카오 알림톡 연동.
이벤트 생성 시 하객에게 초대 알림톡 자동 발송.
하객이 축의금 등록 시 호스트에게 실시간 알림톡.
```

### 하객 명부 엑셀 내보내기
```
[기능 설명]: 이벤트별 하객 명부를 엑셀/CSV로 내보내기.
이름, 금액, 메모, 등록 시간 포함.
Supabase Edge Function으로 파일 생성 후 공유.
```
