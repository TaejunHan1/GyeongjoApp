# 미니멀 카테고리 청첩장 템플릿 프롬프트 (5종)

> ChatGPT (GPT Image) 또는 DALL·E에 그대로 붙여 사용
> 각 템플릿당 **A. preview**(샘플 정보 포함) + **B. template**(빈 프레임) 두 버전
> 결과 파일명: `preview6~10.png` / `preview6templete.png ~ preview10templete.png`
> 비율: **portrait 1024 × 1400 px** (반접지 청첩장 비율)

---

## 공통 스타일 가이드 (모든 미니멀 템플릿 공통)

- **NO flowers, NO leaves, NO botanical elements at all**
- Pure typography-driven design
- Mostly white / off-white background
- Thin lines, geometric shapes only
- Monochrome or single muted accent color
- Generous whitespace, lots of breathing room
- Very thin serif or modern sans-serif typography
- Korean wedding invitation aesthetic — calm, elegant, refined
- Print-ready, flat illustration, no shadows, no 3D
- Final image: portrait 1024x1400 px

## 사용 순서

1. ChatGPT 또는 DALL·E에서 위 프롬프트 그대로 복사 → 이미지 생성
2. 결과를 다음 위치에 저장:
   - **Preview** (샘플 포함): `assets/studio/templete/preview/preview6.png` ~ `preview10.png`
   - **Template** (빈 버전): `assets/studio/templete/preview6templete.png` ~ `preview10templete.png`
3. `mobileTemplateConfigs.js`에 5개 항목 추가 (category: `'minimal'`)

```js
{
  id: 'pure-type',
  name: 'Pure Type',
  subtitle: '순수 타이포그래피',
  category: 'minimal',
  preview: require('../../../../assets/studio/templete/preview/preview6.png'),
  template: require('../../../../assets/studio/templete/preview6templete.png'),
  photo: null,
},
// ...thin-frame, single-line, asymmetric, mono-circle
```

## 프롬프트 작성 팁

- **"NO flowers"**, **"NO illustrations"** 강조 안 하면 ChatGPT가 자동으로 꽃을 넣음
- **"only typography"**, **"only text"** 명시
- **"thin serif"**, **"hairline"**, **"1px"** 으로 선 두께 제어
- **"print-ready flat design"** → 그라디언트·그림자 제거
- **B. Template 버전**에서는 **"BLANK"**, **"NO names"**, **"NO sample date"** 강조 — 안 하면 chatgpt가 임의 텍스트 넣음
