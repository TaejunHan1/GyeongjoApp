# 종이 청첩장 에셋 생성 가이드 (ChatGPT용)

청첩장 디자인 에셋 30개를 ChatGPT로 순서대로 생성하기 위한 복붙용 가이드.

---

## ⚠️ 가장 중요한 규칙 — 진짜 투명 배경

ChatGPT가 **체크무늬(격자 패턴)를 이미지 안에 그려 넣는 경우**가 많음.
그건 **가짜 투명** (그냥 체크무늬가 그려진 이미지일 뿐).

**우리가 원하는 건 실제 알파 채널 투명 PNG** (다운로드해서 다른 배경 위에 올리면 배경이 비쳐 보이는 진짜 투명).

모든 프롬프트에 **"체크무늬 패턴 그리지 말 것, 실제 알파 채널 투명 PNG"** 문구를 넣어야 함.

---

## 🔑 핵심 규칙

- **같은 ChatGPT 대화창**에서 30개 전부 이어서 요청 (새 창 열면 톤 깨짐)
- 한 번에 하나씩 순서대로
- 하루 5~10개씩 3~4일 나눠서 작업 권장

---

## 🏁 1단계 — 대화 시작 (딱 한 번만)

ChatGPT에 **참고할 청첩장 이미지 업로드** + 아래 메시지 복붙.

```
이 이미지 스타일로 한국 결혼 청첩장용 디자인 에셋 30개를 만들 거야.
한 번에 하나씩 순서대로 요청할게.

모든 에셋은 이 규칙을 지켜줘:

【스타일】
- 수채화 스타일, 손으로 그린 느낌
- 세이지 그린 + 아이보리 + 따뜻한 크림 팔레트
- 한글이나 영문 글자 절대 넣지 말기 (글자는 나중에 내가 따로 넣음)

【배경 — 가장 중요】
⚠️ 반드시 실제 알파 채널 투명 PNG로 생성해줘.
⚠️ 투명을 표현하려고 체크무늬·격자무늬 패턴을 이미지 안에 그리지 마.
   (그건 가짜 투명이야. 다운로드하면 체크무늬가 그려진 이미지가 나옴)
⚠️ 흰색·회색·크림색 배경도 X. 배경 영역의 픽셀 값은 완전히 비어있어야 함 (alpha = 0).
⚠️ 오브젝트 주변에 어떤 후광·그림자·프레임·외곽선도 없어야 함.

다운로드했을 때 이미지 편집 프로그램(포토샵·프리뷰·파이어폭스)에서
"진짜 투명"으로 인식되는 PNG여야 해.

【사이즈】
- 1024×1024 기본 (다른 사이즈 지시하면 그거 따라줘)

먼저 1번 에셋부터 시작할게.

[1번] eucalyptus-branch-top-right
용도: 청첩장 앞면 우측 상단 모서리 장식
설명: 가로로 살짝 기울어진 유칼립투스 가지 한 줄기,
      둥근 잎 5~7장, 줄기가 왼쪽 아래에서 오른쪽 위로 뻗음,
      방금 올린 참고 이미지의 우측 상단 장식처럼
배경: ⚠️ 실제 알파 채널 투명 PNG · 체크무늬 그리지 말 것 ·
      흰색/회색/어떤 색 배경도 X · 그림자·외곽선 없음
사이즈: 1024×1024

이걸 먼저 만들어줘.
```

→ 결과 다운로드 전 **반드시 체크**: 이미지에 체크무늬가 그려져 있으면 재요청.
→ 이상 없으면 `1-eucalyptus-branch-top-right.png`로 저장.

```
사이즈: 1024×1024 (또는 원하는 크기)
```

## 🚨 재요청 문구 (체크무늬 나왔을 때)

```
지금 이미지 배경에 체크무늬(격자 패턴)가 그려져 있어.
그건 가짜 투명이야. 체크무늬를 이미지 안에 그리지 말고,
진짜 알파 채널 투명 PNG로 다시 만들어줘.
배경 영역은 완전히 비어있어야 해 (픽셀 값 없음, alpha = 0).
흰색/회색/크림색 배경도 넣지 말고, 어떤 색도 칠하지 마.
```

## 💡 작업 팁

### 중간에 톤이 이상해지면
```
잠깐, 에셋 #1과 비교했을 때 색상 톤이 좀 달라진 것 같아.
#1의 세이지 그린 톤으로 다시 맞춰서 이번 에셋을 다시 만들어줘.
```

### 결과 수정 요청
```
이건 수정 필요해.
- 잎이 너무 큼 → 30% 작게
- 줄기가 너무 진함 → 연하게
같은 에셋을 이 피드백 반영해서 다시 만들어줘.
```

### 🚨 체크무늬(가짜 투명) 나왔을 때
```
지금 이미지 배경에 체크무늬(격자 패턴)가 그려져 있어.
그건 가짜 투명이야. 체크무늬를 이미지 안에 그리지 말고,
진짜 알파 채널 투명 PNG로 다시 만들어줘.
배경 영역은 완전히 비어있어야 해 (픽셀 값 없음, alpha = 0).
흰색/회색/크림색 배경도 넣지 말고, 어떤 색도 칠하지 마.
```

### ChatGPT가 계속 체크무늬를 고집할 때 (우회 방법)
ChatGPT는 아직 100% 알파 채널 PNG 생성을 못할 때가 있음.
그럴 땐 **단색 배경(연한 민트색 #C8E6C9 or 라임색)** 으로 요청한 뒤 배경 제거 도구로 후처리:

```
배경을 연한 라임색(#C0FF00)으로 단일 색상으로 만들어줘.
오브젝트 주변에 후광·그림자·외곽선 없이 딱 단색 배경.
```

→ 이후 **remove.bg**(무료 월 50장) 또는 **Clipdrop Cleanup**(무료)에 업로드 → 배경 제거 → 진짜 투명 PNG 완성.

### 업스케일 (인쇄용 필수)
- 도구: **Upscayl** (무료, upscayl.org)
- 4× 업스케일로 한번에 30장 처리
- 청첩장 인쇄용은 300dpi · 최소 2500px 필요

### 투명 배경 후처리
- **remove.bg** (무료 월 50장) — 가장 안정적
- **Clipdrop Cleanup / Background Remover** (무료) — 대체 옵션
- ChatGPT 결과물 가장자리에 흰 프린지가 남거나 체크무늬가 섞여있으면 반드시 한 번 더 세척
