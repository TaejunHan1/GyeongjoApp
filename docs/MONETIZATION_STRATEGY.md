# 경조사앱 수익화 전략

## 📋 현재 상황 분석
- **기존 서비스**: 모바일 청첩장/부고장 생성 + QR 스캔 장부 관리
- **문제점**: 직접적인 수익 창출 구조 부재
- **시장 현실**: 웨딩홀에서 모바일 청첩장을 무료 제공하는 추세

## 💰 핵심 수익화 모델

### 1. 기본 무료 + 필요시 결제 구조

#### 🆓 기본 무료 플랜
- **이벤트 생성**: 결혼식 1개 + 장례식 1개
- **템플릿**: 모든 기본 템플릿 이용 가능
- **장부 보관**: 1주일 무료 보관
- **기본 통계**: 총 금액, 참석 인원수

#### 💳 필요시 결제 서비스
- **장부 + 총비용관리 1달 연장**: 5,500원
  - 부조금 장부 관리
  - 총 지출 비용 관리 (예식장, 드레스, 화환, 음식 등)
  - 수익/지출 분석 및 통계
- **추가 이벤트 생성**: 건당 9,900원
- **프리미엄 템플릿**: 3,900원~19,900원

### 2. 총 비용 관리 기능 (장부와 통합)

#### 결혼식 지출 관리
- 예식장 비용
- 드레스/턱시도 대여비
- 화환/부케 비용
- 음식/피로연 비용
- 사진/영상 촬영비
- 예물/혼수 비용

#### 장례식 지출 관리  
- 장례식장 비용
- 화환/조화 비용
- 음식 접대비
- 상복 구입비
- 기타 장례용품

#### 분석 기능
- **순 수익 계산**: 총 부조금 - 총 지출
- **카테고리별 지출 분석**: 어디에 가장 많이 썼는지
- **비교 분석**: 평균 대비 내 지출 수준
- **절약 팁**: AI 기반 절약 제안

### 3. 광고/제휴 수익 모델 ⭐⭐⭐

#### 광고 배치 위치
1. **홈 화면**: 상단 배너 (웨딩홀, 드레스샵)
2. **가이드 섹션**: 각 가이드 하단에 관련 업체 광고
3. **이벤트 생성 완료 후**: "축하합니다! 특별 할인 혜택 받아가세요"
4. **내 행사 상세 화면**: 우측 상단 "혜택" 버튼

#### 제휴 할인 쿠폰
- **드레스샵**: 10-20% 할인
- **플로리스트**: 15% 할인
- **웨딩 사진 스튜디오**: 패키지 할인
- **예물/혼수 브랜드**: 특가 혜택
- **장례용품점**: 10-15% 할인
- **웨딩홀**: 시즌 특가 정보

#### 수익 구조
- **광고비**: 월 50만원~200만원 (지역별/업체별)
- **제휴 수수료**: 거래 금액의 10-20%
- **프리미엄 배치**: 상단 노출 추가 비용

### 4. 프리미엄 템플릿 마켓플레이스

#### 운영 방식
- **디자이너 등록제**: 포트폴리오 심사 후 승인
- **수익 분배**: 디자이너 70% + 플랫폼 30%
- **품질 관리**: 사용자 평점 및 리뷰 시스템

#### 가격 정책
- **심플 템플릿**: 3,900원
- **스탠다드 템플릿**: 9,900원  
- **프리미엄 템플릿**: 15,900원
- **럭셔리 템플릿**: 19,900원

#### 미리보기
- 워터마크 있는 샘플 제공
- 실제 구매 전 스타일 확인 가능

## 🚀 단계별 구현 전략

### Phase 1: 즉시 적용 (1개월 내)
1. **제휴 할인 쿠폰 시스템** 구축
   - 지역 드레스샵 5-10곳과 제휴 협약
   - 할인 쿠폰 UI/UX 개발
2. **광고 배너 시스템** 구축
   - 홈 화면 상단 배너 슬롯
   - 가이드 하단 네이티브 광고
3. **장부 연장 결제** 시스템
   - 1주일 후 알림 발송
   - 5,500원 결제 연동

### Phase 2: 중기 개발 (1-2개월)
1. **프리미엄 템플릿 마켓플레이스**
   - 디자이너 모집 및 심사
   - 템플릿 업로드/구매 시스템
2. **총 비용 관리 기능**
   - 지출 카테고리별 입력 UI
   - 수익/지출 분석 대시보드
3. **제휴 업체 확대**
   - 웨딩홀, 사진관까지 확장
   - 지역별 파트너십 확대

### Phase 3: 장기 발전 (3-6개월)
1. **AI 기반 맞춤 추천**
   - 지역/예산별 업체 추천 알고리즘
   - 사용자 행동 패턴 분석
2. **VIP 프로그램**
   - 단골 고객 등급제 도입
   - 독점 혜택 및 템플릿 제공
3. **B2B 진출**
   - 웨딩홀 대상 솔루션 제공
   - 화이트라벨 서비스 개발
