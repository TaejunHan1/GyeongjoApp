# 계약 전 질문 카드 Feature Spec

## 기능명

계약 전 질문 카드

## 문제 정의

정담에는 예식비 진단이 이미 있다. 그래서 새 기능은 견적을 다시 계산하거나 비싼지 판단하는 기능이 아니라, 계약 상담 자리에서 놓치면 나중에 비용과 분쟁으로 이어지는 질문을 정리하는 기능이어야 한다.

사용자는 예식장이나 장례식장 상담에서 무엇을 물어봐야 하는지 모르는 경우가 많다. 질문 카드 기능은 계약서에 남겨야 할 항목, 구두 약속으로 끝내면 위험한 항목, 추가 비용이 붙기 쉬운 항목을 상황별로 보여준다.

## 사용자군

- 결혼 주최자: 예식장 상담 전 식대, 보증인원, 취소 위약금, 주차, 특약을 확인한다.
- 장례 주최자/상주: 빈소료, 장례용품, 식사, 발인/장지 일정, 정산 서류를 확인한다.
- 앱 비회원/게스트: 가이드 먼저 보기에서 계약 질문을 확인할 수 있다.

## 핵심 사용자 흐름

1. 가이드 탭에서 `행사를 준비해요`를 선택한다.
2. `계약 전 질문 카드`를 누른다.
3. 결혼식/장례식을 선택한다.
4. 비용, 인원·식사, 취소·변경, 현장, 서류 칩으로 질문을 좁힌다.
5. 질문 카드에서 이유, 확인할 항목, 위험 신호를 본다.
6. 필요한 질문을 복사해 상담 메모장에 붙여둔다.

## 화면 목록

- 가이드 탭 주최자 카드
- 계약 전 질문 카드 화면
- 결혼식/장례식 세그먼트
- 질문 그룹 칩
- 꼭 물어볼 질문 요약 카드
- 질문 상세 카드

## 상태 목록

- 기본: 결혼식, 전체 질문 목록
- 선택: 결혼식/장례식 전환
- 필터: 질문 그룹 칩 선택
- 성공: 질문 복사 후 `복사됨` 표시
- 빈 상태: 현재 없음. 모든 그룹에 기본 질문이 있다.
- 에러: 클립보드 실패 처리는 다음 루프에서 커스텀 토스트로 확장 가능

## 디자인 원칙

- 토스 스타일의 조용한 흰 카드와 칩 UI를 사용한다.
- 기본 picker/dropdown을 쓰지 않는다.
- 계산 화면처럼 보이지 않게 질문, 이유, 위험 신호 중심으로 구성한다.
- 상담 자리에서 바로 읽을 수 있도록 문장을 짧게 유지한다.

## 데이터 영향

- 신규 DB 없음
- 신규 RPC 없음
- 결제/크레딧 영향 없음
- 로컬 정적 질문 데이터만 사용
- 클립보드 복사만 사용

## 고위험 영역

- 법률 자문처럼 보이면 안 된다.
- 지역/업체별 세부 계약 조건은 다를 수 있으므로 확정 표현을 피한다.
- 질문이 너무 많으면 사용자가 읽지 않으므로 필수 질문과 전체 질문을 나눈다.

## MVP 범위

- 결혼식 질문 6개
- 장례식 질문 6개
- 결혼식/장례식 전환
- 질문 그룹 필터
- 꼭 물어볼 질문 요약
- 개별 질문 복사
- 비회원 가이드 네비게이션 연결

## 제외 범위

- 견적 판독
- 가격 퍼센트 계산
- OCR/사진 업로드
- 질문 커스터마이징 저장
- 체크 완료 저장
- 업체별 실제 계약서 비교

## 완료 조건

- 가이드 주최자 화면에 `계약 전 질문 카드`가 보인다.
- 로그인/비로그인 네비게이션에서 화면 진입이 가능하다.
- 결혼식/장례식 세그먼트가 작동한다.
- 그룹 칩 필터가 작동한다.
- 질문 복사 시 복사 상태가 보인다.
- JSX 파싱이 통과한다.
